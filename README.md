## 🇵🇹 Português

### Sobre o projeto

O **GreenGadget** é um projeto desenvolvido por mim no âmbito do meu percurso académico em Engenharia Informática.

O projeto consiste no desenvolvimento de um sistema de monitorização e gestão do cultivo de plantas, com especial enfoque na automatização da rega e na utilização eficiente dos recursos.

A solução integra componentes de hardware e software, incluindo módulos ESP32, sensores ambientais e de humidade do solo, uma API, uma base de dados, um servidor e uma aplicação móvel.

**GreenGadget** is a project developed by me as part of my academic studies in Computer Engineering.

The solution integrates hardware and software components, including ESP32 modules, environmental and soil moisture sensors, an API, a database, a server, and a mobile application.
